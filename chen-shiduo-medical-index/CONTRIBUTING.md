# 贡献指南

## 可接受的贡献

- 核对八部著作的目录、卷次、篇章和论题词。
- 添加来源明确的索引别名。
- 改进确定性检索、测试、文档和小程序接入示例。
- 修正来源链接、错别字和数据结构问题。

## 不接受的贡献

- 来源不明或未经授权的现代版本全文、扫描件和 OCR。
- 患者信息、真实就诊记录、账号、密钥或内网配置。
- 未经医院审核的诊断规则、处方推荐、剂量换算和疗效声明。
- 将古代病名直接映射为现代疾病诊断的内容。

## 添加索引

1. 阅读 `references/data-schema.md`。
2. 为每条记录填写稳定 `id`、卷次、篇章、论题词、来源和核对状态。
3. 将现代输入词放在 `keywords`，保留 `topic` 的古籍原称。
4. 将科室配置与古籍条目分开维护。
5. 添加成功、无匹配和急症优先级测试。
6. 运行以下命令：

```bash
python -m unittest discover -s tests -v
python scripts/build_index.py
```

7. 在提交说明中列出来源、核对范围和未覆盖部分。

## 医疗安全变更

修改 `navigation.json` 或 `emergency.json` 时，应说明审核依据和测试范围。患者端生产配置必须由医院授权人员审核，开源仓库中的演示配置不能直接视为临床标准。
